### useState에서 setValue 함수는 비동기로 처리됨
```               
            const handleChange = (event) => {
                const { name, value } = event.target;
                setForm((prev) => ({
                ...prev,
                [name]: value,
                }));
                console.log(form);
            };

            <label className="input-group">
                <span className="input-label">계급</span>
                <select name="rank" className="text-input" onChange = {handleChange}>
                  {
                    rankList.map((name, index)=>{
                      return(
                       <option value={`${index}`}>{name}</option>
                      )
                    })
                  }
                </select>

            </label>

```

**여기서 select의 항목을 바꿀때 처리되는 순서 :**
1. onChange리스너가 실행됨
2. handleChange함수 실행
3. event에 change된 객체 이벤트 반영됨.
4. setForm(...) 실행 x => 비동기 함수이므로 이벤트 큐에 들어감
5. console.log(form) 실행
6. 따라서 form은 setForm이 반영되기 이전의 정보를 출력한다~
